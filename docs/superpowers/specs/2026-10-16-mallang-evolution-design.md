## 2. 코어 루프 — 하이브리드

```
[일반 에포크]  사건 서술 + 위기 → 진화 선택 3보기 → 스탯 즉시 갱신 → 다음
                                    ↓ 실패 시
                              [구원 선택] 3보기 (축별 대가 지불) → 실패+1
                                    ↓ 3회 누적
                              [완전 멸종 엔딩]

[대멸종 에포크] 위와 동일 판정 → 생존/구원 통과 후 반드시
                                    ↓
                              [방산] 변종 3보기 중 후계자 1개 선택
                                    ↓ 버린 2개는 평행세계 수첩에 기록
```

- **클릭 수**: 일반 에포크 9×1 = 9, 대멸종 에포크 5×2 = 10, **총 19회**
- 실패가 발생하면 그때만 +1클릭 (최대 3회 추가)
- 모든 클릭이 결정으로 이어짐 — "다음" 전용 버튼 없음

### 2.1 왜 대멸종마다 방산을 강제하는가

생물학적으로 대멸종 직후엔 **적응 방산(adaptive radiation)** 이 일어난다 — 빈 생태적 공간을
여러 계통이 급속히 나눠 차지한다. 그래서 **게임 리듬 전환 + 생물학 정확성**이 동시에 성립한다.
또한 이 방식이 "선택이 결과를 바꾸는가"를 증명하게 해준다: 방산에서 고른 변종이 이후 4개 에포크의
스탯과 외형을 그대로 물려받는다.

## 3. 스탯 모델 — 4축

| 축 | 내부 키 | 뜻 | 높으면 좋은 시기 |
|---|---|---|---|
| 강인 | `might` | 각질·내열·회복력 | 대멸종·극단 환경 |
| 민첩 | `agile` | 감각·이동·회피 | 포식 압박·기후 급변 |
| 활력 | `vital` | 대사 효율·번식력 | 자원 부족·기생 |
| 지혜 | `wise` | 신경계·사회·학습 | 복잡 환경·내부 경쟁 |

- 초기값: `might 55 / agile 48 / vital 52 / wise 10`
- 범위 0~100, 각 선택이 2~4개 축에 ±6~22 값을 줌
- **판정**: 에포크별 가중합 `score = Σ(stat[i] × weight[i])` ≥ `threshold` → 생존

### 3.1 "이번 위기가 뭘 시험하나" — 가시화 (caveman 교훈 #4)

매 에포크 상단에 **위험 축 배지**를 표시한다: `이번 위기: 강인 ×0.34 · 활력 ×0.24 …`
플레이어가 목표 축을 선제적으로 키울 수 있게 해, 추상적인 스코어를 전략으로 바꾼다.

## 5. 방산 (대멸종 직후)

- 각 대멸종 에포크에 변종 3개. 각 변종 = `{name, desc, deltas, parts, parallelFuture}`
- 후계자 선택 시: 스탯 즉시 반영 + **외형 파츠가 실제로 바뀐다** (5번 째 방산이면 전부 다른 creature)
- **버린 2개는 `parallelWorld` 배열에 `{name, deltas, future}`로 누적** → 엔딩에서 카드로 노출

### 5.1 평행세계는 카메오 방식

평행세계는 **별도 시뮬레이션이 아니다.** 선택을 되돌리는 오브젝트다.
엔딩에서 "만약 그때 이 변종을 골랐다면" 형태로 각 변종의 `future` 문장을 보여준다.
계산 비용 0, 인과 서사는 동일 — 이게 이 게임의 "분기점"이다.

## 6. 엔딩 (12종, 전부 계산 생성)

```
tier     = failCount === 0 ? 'perfect'
         : failCount < 3   ? 'scarred'
         :                  'extinct'
archetype = argmax(stat) → 'might' | 'agile' | 'vital' | 'wise'
ending   = ENDINGS[tier][archetype]   // 3 × 4 = 12
```

- **perfect + 지혜** → "생각하는 말랑" — 가장 밝은 결말
- **extinct** → 완전 멸종. 그러나 평행세계 10개 카드는 그대로 열람 가능 (플레이어는 끝까지 결과를 본다)
- 엔딩 화면 구성: 결과 카드(종명·도달 에포크·지배 형질·평균 지수) / 한 줄 서사(클립보드 복사) / **평행세계 카드 그리드** / 38억 년 선택 기록 / 재시작

### 6.1 종명 생성

`원시종 말랭이` → 선택마다 `nameFragment` 가 쌓여 `갑말랭이` → `갑솜랭이` → …
각 선택이 음절 하나를 교체한다. 같은 선택 순서 = 같은 종명(결정론), 다른 순서 = 다른 종명.

|---|---|---|

## 10. 검증 계획 (구현 완료의 근거)

Node 하네스로 `3^14 = 4,782,969` 경로를 **메모이제이션 DP**(동일 스탯 상태 재사용)로 전수 탐색:

1. **완전 멸종 도달 가능** — `failCount 3` 경로 ≥ 1
2. **전 에포크 무사 통과 가능** — `failCount 0` + epoch 14 도달 경로 ≥ 1
3. **엔딩 12종 전부 출현** — `tier × archetype` 조합 커버리지 12/12
4. **난이도** — 무작위 정책(균등 랜덤) 10,000회 시뮬레이션에서 생존률 및 평균 실패횟수 측정 → 난이도 구간 설정
5. **결정론** — 동일 시드 2회 실행 결과 해시 동일
6. **브라우저 스냅샷** — Playwright 데스크톱(1440×900)·모바일(390×844) 스크린샷 육안 검토 + 상호작용 스모크

**합격 기준**: 위 6개 전부 통과해야 구현 완료로 인정. 하나라도 실패 시 임계값·선택지 밸런스 재튜닝 후 재실행.
